🎤 Perguntas Clássicas de Entrevista Técnica

1. Qual a diferença entre TCP e UDP?

Resposta: TCP é orientado à conexão, garante entrega e ordem dos pacotes (ex: HTTP/HTTPS, SSH). UDP é sem conexão, mais rápido e sem retransmissão, ideal para streaming, DNS e VoIP.

2. O que é o Modelo de Responsabilidade Compartilhada da AWS?

Resposta: A AWS é responsável pela segurança DA nuvem (hardware, data centers, rede física). O cliente é responsável pela segurança NA nuvem (dados, IAM, regras de firewall/Security Groups e atualização do SO em EC2).

3. O que acontece quando você digita um site no navegador?

Resposta: Resolução DNS para descobrir o IP → Three-way handshake TCP → Negociação TLS (HTTPS) → Requisição HTTP GET → Resposta do servidor e renderização.
